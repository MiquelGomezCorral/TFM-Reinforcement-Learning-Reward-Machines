# Conventions

## Code Style

Python source uses standard imports, type annotations on some public functions, and docstrings on modules, classes, and functions. No formatter or linter command is configured.

## Naming

Functions and modules use `snake_case`; classes use `PascalCase`. The current training flow passes the configuration as `CONFIG`.

## Imports

Code under `app/` imports application modules through the `src` and `scripts` packages.
